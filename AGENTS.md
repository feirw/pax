## Application rules
- Keep briefing content, risk series, and mock answers in a browser-safe data module so an API can replace the mock source without changing presentation.
- Use browser speech synthesis for mock narration and a shared 60-second playback clock; no remote services are required.
- Keep Supply Signal visual tokens and animation rules in the global stylesheet, and use design-system Button variants for controls.
